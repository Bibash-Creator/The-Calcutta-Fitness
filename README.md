# The Calcutta Fitness — Elite Gym Website

A premium, responsive website for **The Calcutta Fitness Studio** — Kolkata's elite training ground on Jamini Roy Sarani.

## Tech Stack

- **React 19** + **TypeScript**
- **Vite 7** (build tool)
- **TailwindCSS 4** (styling)
- **Lucide React** (icons)

## Getting Started

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Features

- Fully responsive single-page website
- Smooth scroll navigation
- Interactive BMI calculator
- Class schedule with day tabs
- Pricing plans with monthly/annual toggle
- Contact form with validation
- Google Maps embed
- WhatsApp floating button
- Mobile hamburger menu
